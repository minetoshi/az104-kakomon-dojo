# AZ-104 過去問道場

AZ-104 学習用の問題データと、ブラウザーで使える過去問道場ページを保存する private リポジトリです。

## 現在の収録内容
- 第1セット: 50問
- 第2セット: 50問
- 合計: 100問
- 各セットは元の問題番号 1〜50 の順序を維持
- 第1セットと第2セットは別IDで管理し、回答履歴が混ざらないようにしています

## 過去問道場
`index.html` から利用できます。

主な機能:
- 全100問 / 第1セット / 第2セットの切り替え
- 番号順 / ランダム / 間違えた問題のみ
- カテゴリ絞り込み
- 出題数指定
- 選択肢シャッフル
- 未回答のみ
- 単一選択 / 複数選択対応
- 正誤判定、解説
- 問題一覧から移動
- 学習履歴をブラウザーの localStorage に保存
- 回答後に関連する Microsoft Learn 公式ページへのリンクを表示

## ファイル構成
- `index.html` : 過去問道場本体
- `learn-map.js` : 第1セットの Microsoft Learn 関連リンク
- `questions/set-01/*.js` : 第1セット 50問
- `questions/set-02/*.js` : 第2セット 50問
- `questions/q01-10.json` ～ `questions/q41-50.json` : 第1セット作成時の元データ（互換・照合用）

## 利用方法
GitHub Pages で公開するか、リポジトリを取得してローカルのWebサーバーから `index.html` を開いてください。

例:
```bash
python -m http.server 8000
```

その後、ブラウザーで `http://localhost:8000/` を開きます。

## データ方針
- 問題文と選択肢は提供された Microsoft Learn プラクティス評価のスクリーンショットを基に保存しています。
- 正答・解説は問題内容と Microsoft Learn の現行ドキュメントを基に整理しています。
- Azure の仕様は更新されるため、回答後の Microsoft Learn リンクも併せて確認できる構成にしています。
- 第2セット問27は、プラクティス評価の選択肢と現行 Azure のリソースロック挙動に注意が必要なため、過去問道場上でも注意書きを表示します。
