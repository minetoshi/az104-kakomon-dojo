# AZ-104 過去問道場

AZ-104 学習用の問題データと、ブラウザで解ける「過去問道場」ページを保存するリポジトリです。

## 現在の収録数
- 全100問
- 第1セット: 問1〜50
- 第2セット: 問51〜100（追加スクリーンショット50問）
- 問題番号は必ず昇順で表示し、勝手にシャッフルしません。

## 過去問道場
`index.html` に100問対応のページを実装しています。

主な機能:
- 1→100の固定順
- 第1セット / 第2セット / 全100問の切り替え
- カテゴリ絞り込み
- 単一選択 / 複数選択対応
- 「回答を確認」で正誤判定
- 正答と解説を表示
- 各問題に Microsoft Learn の関連リンクを表示
- 正解数・回答数・正答率を表示
- 問題一覧から直接ジャンプ
- 進捗をブラウザの localStorage に保存
- iPhone でも使いやすいレスポンシブ表示

## 問題データ
- `questions/q01-10.json`
- `questions/q11-20.json`
- `questions/q21-30.json`
- `questions/q31-40.json`
- `questions/q41-50.json`
- `questions/q51-60.json`
- `questions/q61-70.json`
- `questions/q71-80.json`
- `questions/q81-90.json`
- `questions/q91-100.json`

各問題には以下を保存しています。
- 問題文
- 選択肢
- 正答
- 解説
- カテゴリ
- 元セット内の問題番号
- Microsoft Learn の関連リンク

## 品質方針
- 問題の順番は保持する
- スクリーンショットの内容を基準に問題文・選択肢を保存する
- 正答は Azure の仕様と Microsoft Learn を基準に確認する
- 問題データのID重複・欠番・正答インデックス・Learnリンク有無を検証する
