## 要注意設問
- **s1-q19 — 注記あり**: Practice想定と現行App Service移動ガイダンスの証明書表現に差異
- **s1-q34 — 注記あり**: Tag Contributor と subscription scope の指定まで理解が必要
- **s1-q46 — レガシー注意**: Practice想定14日。現行Learnでは最大14日の明示を確認できず
- **s2-q13 — レガシー注意**: Azure Backup Secure by Default により soft delete の現行挙動が変化
- **s2-q18 — 注記あり**: P1 は hybrid SSPR/password writeback 前提
- **s2-q19 — 注記あり**: B2B guest のパスワード権威は home tenant 側
- **s2-q26 — 注記あり**: Tag Contributor + subscription scope の指定が必要
- **s2-q27 — 現行仕様と不一致**: RG の CanNotDelete lock は RG 自身の削除もブロック
- **s2-q48 — 注記あり**: 現行UIでは Client IP and protocol は1つのモード
