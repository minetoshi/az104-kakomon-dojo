古いPractice問題で特に注意

  • Storage IDベースアクセス: Practiceの「Files」文脈を一般化しない。現行StorageはBlob/File/Queue/TableでEntra認可を利用可能。
  • Load Balancer 5-tuple: 5-tupleは現在も正しいが既定。タイムアウト診断ではprobe・backend・NSGも確認。
  • Log Analytics dashboard 14日: Practice想定として残しているが、現行仕様値として固定暗記しない。
  • Recovery Services vault削除: Secure by Default / soft delete の現行挙動をLearnで確認。
  • Resource Group lock: RGへCanNotDeleteを付けるとRG自身の削除もブロックされる。
  • ACR roles: RBAC Registry PermissionsとABAC対応モードでデータプレーンロールが変わる。

本番100分の使い方

  • 最初の周回は迷う問題に時間を使いすぎず、フラグして進む。
  • 「最小権限」「管理作業を最小化」「コストを最小化」「private」「自動」という制約語を先に拾う。
  • 複数選択は、正解候補を1つずつ独立に要件へ照合する。
  • ケース/長文では、構成情報より先に最後の質問文を読む。
  • 最後に未回答が残らないよう、時間切れ前に全問へ回答する。
