12か月無料を活用

AZ-104 12か月無料ハンズオン

12か月無料の対象アカウントを使い、無料枠が公式に明示されているサービスだけを実機で触ります。無料枠外の機能は マニュアル学習 に回します。

最重要: 12か月無料は「対象サービスの月間無料量」までです。無料枠を超えた分、無料対象外SKU、付随する Public IP / Private Endpoint / Load Balancer / egress などは別料金になり得ます。Azure Portal の Cost Management + Billing ＞ Free services で、あなたのサブスクリプションに表示される残量・対象SKUを毎回確認してください。

Lab 1: Resource Group / Tag / Lock / RBAC

試験: RBACは「誰が何をできるか」、Policyは「どんな構成を許すか」、Lockは「削除/変更保護」、Tagは「分類」。

Lab 2: VNet / Subnet / NSG / UDR

Route table ＞ Routes

Next hop IP10.10.1.4（例。NVA実体は作らなくてよい）
試験: VNet Peering は非推移的。重複アドレス空間では作れない。NSGがNICとSubnetの両方にある場合、両方を通過する必要がある。

Lab 3: Blob Storage

  1. Blob container を Private で作成。
  2. 1KB程度のテキストを upload。
  3. Blob versioning と soft delete を有効化。
  4. ファイルを書き換え、以前の version が残ることを確認。
  5. 削除→soft-deleted blob の復元を確認。
  6. Lifecycle rule を作成して「一定日数後に Cool」条件を見る。大量データは置かない。
  7. Service SAS と User delegation SAS の作成画面を比較。
試験: versioning=旧版、soft delete=削除復元、lifecycle=自動tier/削除、immutable=WORM。User delegation SAS=Entra ID。

Lab 4: Azure Files

試験: SMBはTCP 445。File share snapshot はポイントインタイムコピー。soft delete は削除された share の復元。

Lab 5: AzCopy / Storage Explorer

azcopy copy "./sample.txt" "https://<account>.blob.core.windows.net/<container>/sample.txt?<SAS>"
試験: Storage Explorer=GUI、AzCopy=大量データ転送向けCLI。

Lab 6: 無料対象 VM + Managed Disk

  • VM SKU は あなたの Free services 画面に表示される対象SKUを選ぶ。
  • Public IP: None。
  • OS/Data disk: 無料枠対象の P6 64GB を意識。
  • RDP/SSH のために有料サービスを追加しない。必要な確認は Portal の Run command / Resource view を優先。
  • Resize は有料SKUへ変更しない。画面だけ確認し、実操作は マニュアル。
  1. VM作成。
  2. 2本目の無料枠対象 Managed Disk を attach。
  3. Data disk を detach → 再attach。
  4. VM の Redeploy + reapply 画面を確認。
  5. Snapshot は無料枠の1GBを超えないよう、空に近いData diskで1つだけ試すか、画面確認のみ。
  6. 終わったら VM、disk、NIC を含めリソース削除。
試験: Resize=VM SKU変更、Redeploy=別ホストへ再配置、Detach/Attach=Data disk移動。Public IPはVMの必須要素ではない。

Lab 7: Azure Container Registry

  1. ACR作成時に Standard を選択。
  2. Access control (IAM) で AcrPull / AcrPush の説明を確認。
  3. Registry permissions mode が ABAC 対応の場合は Repository Reader / Writer 系へロール体系が変わる点を確認。
  4. Repository 一覧を確認。実イメージは小さいもの1つまで。
試験: 問題文に Registry permissions mode があるか確認。RBAC-only と ABAC 対応モードでロール体系が異なる。

Lab 8: App Service Free tier

試験: Standard以上が必要な autoscale、Deployment slots、ネットワーク統合等を Free tier の体験と混同しない。

Lab 9: Container Apps（任意）

試験: Container Apps の scale rule / event-driven scale / sidecar の概念を問題演習と結び付ける。
