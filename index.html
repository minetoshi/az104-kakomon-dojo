勉強と本番模試を分けて使う

勉強モードは公式試験範囲と Microsoft Learn の関連製品まで含む全366問。模試モードは本番範囲だけから50問を出題し、解答中は正誤・解説を表示しません。

勉強する

全範囲を、実戦に近い問題で覚えるモードです。

  • 全366問が学習対象
  • 過去問 + 類似 + 公式補強 + Learn製品
  • 解答直後に全選択肢の解説 + Learn
  • 初期設定はランダム + 選択肢シャッフル

模試を受ける

本番を想定して、時間と分野比率を固定します。

  • 50問 / 100分
  • 公式試験範囲のみ
  • 類似問題・Learn周辺製品は除外
  • 終了後に分野別成績を確認

勉強する

全366問で全範囲を学習

全範囲を学習対象にしています。公式82スキル細目 + Microsoft Learn に登場する関連製品まで含め、問題を解きながら覚える構成です。初期設定はランダム出題・選択肢シャッフルです。

過去問は元の問題番号順を維持し、同じ論点を別シナリオで問う類似問題100問に加え、2026年4月17日時点の Microsoft Learn AZ-104 学習ガイドを再監査し、Bicep・TLS・Insights・Site Recovery に加えて、VM作成・VNet/Subnet・Storage冗長性・コンテナー構成・Backup/Restore など問題学習で薄かった論点まで補う160問を追加しています。さらに、AZ-104 の公式 Microsoft Learn 学習パスに製品として掲載される周辺サービスのうち、既存問題で直接学べていなかった Cloud Shell、Entra Domain Services、AKS、ExpressRoute、Azure Firewall、Azure Virtual Desktop も Learn製品補強として追加しています。回答後は正解・全選択肢の解説と Microsoft Learn 公式ページを表示します。

おすすめ学習ルート

上から順番に進めるのがおすすめです。各分野は未回答を優先して1回20問。全問を一度解いて通算正答率80%以上になると「完了」です。
