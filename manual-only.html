課金なしで読む

課金リスク項目 操作マニュアル

実際に有料リソースを作らなくても、Portal の画面遷移・設定項目・確認ポイント・試験での判断を追えるようにした「ハードコピー風」教材です。

方針
このページの内容は、料金が発生する可能性のある Azure リソースを実際に作成しなくても学習できるようにしています。画面名や設定名は Azure Portal の現行仕様に合わせますが、Portal UI は将来変更される可能性があります。

1. VM / Disk / Resize / Redeploy

Azure Portal ＞ Virtual machines ＞ Create
Resource grouprg-az104-lab
Availability optionsAvailability zone / Availability set
ImageWindows Server または Linux
SizeVM SKU
Public inbound portsNone / RDP / SSH
  1. VM作成画面で Availability option と Size を確認。
  2. Disks で OS disk / Data disk を確認。
  3. VM ＞ Size は Resize、Redeploy + reapply はホスト再配置の切り分けと理解。
  4. Data disk は detach → 別VMへ attach の流れ。
試験ポイント: Resize=SKU変更、Redeploy=別ホストへ移動、Move=RG/Subscription/Region移動。Availability Zone と Availability Set を混同しない。

2. VM Scale Sets

Virtual machine scale sets ＞ Scaling / Upgrade policy
ScalingManual / Autoscale
MetricCPU Percentage など
Upgrade policyRolling / Manual / Automatic
Rolling: バッチ更新で可用性を保ちやすい。
Manual: モデル変更後も既存インスタンスは手動更新。

3. Azure Container Registry

Container registries ＞ Access control (IAM)
RBAC Registry PermissionsAcrPull / AcrPush
RBAC + ABAC Repository PermissionsRepository Reader / Writer 系
試験ポイント: 問題文の「レジストリの権限モード」を必ず確認。AcrPull/AcrPushを無条件に選ばない。

4. App Service

App Service ＞ Configuration / Networking / Deployment slots
HTTPS OnlyHTTP→HTTPS強制
Minimum TLS version1.2 など
VNet IntegrationApp Service から VNet への outbound
Private EndpointVNet から App Service への private inbound
Deployment slotsstaging / production / swap
試験ポイント: VNet Integration と Private Endpoint は向きが違う。Slot setting は swap されない設定として扱う。

5. Storage / SAS / Private Endpoint

Storage account ＞ Networking / Data protection / Shared access signature
NetworkingPublic access / Selected networks / Private Endpoint
Data protectionVersioning / Soft delete / Change feed
SASService / Account / User delegation
Stored access policyService SAS と関連付け
試験ポイント: User delegation SAS=Entra ID。Stored access policy と結び付けるのは Service SAS。Private Endpoint は private IP を作る。

SMB PortTCP 445
Identity-based accessEntra / AD DS 系の構成
ProtectionShare snapshot / Soft delete

7. Networking / UDR / Load Balancer

Route table ＞ Routes
Address prefix0.0.0.0/0

Load Balancer ＞ Rules / Health probes
FrontendPublic IP / Private IP

試験ポイント: Probe=正常性、Distribution mode=振り分け、Session persistence=固定性。別概念。

8. Network Watcher

9. Azure Monitor / Alerts

Azure Monitor ＞ Alerts / Diagnostic settings
Alert ruleいつ発火するか
Action group通知先・Webhook・Runbook等
Alert processing rule通知抑制・Action Group加工
Diagnostic settingsLog Analytics / Storage / Event Hub へ送信
KQL: where=行の絞り込み、project=列選択、summarize=集計。

10. Backup / Site Recovery

Recovery Services vault / Backup vault
Recovery Services vaultAzure VM Backup / MARS / Site Recovery
Backup vaultAzure Disk Backup など
Backup policySchedule / Retention / Instant Restore
Site Recovery ＞ Replicated items ＞ Failover
Test failover本番影響なしのDR訓練
Failover実際の切替

Re-protect逆方向のレプリケーション開始
試験ポイント: Test failover と本番Failoverを区別。Failover後は検証→Commit→Re-protect。

このページの使い方

  1. 各セクションの「Portal経路」を見て、画面を頭の中で再現する。
  2. 設定値を隠して、自分なら何を選ぶか答える。
  3. 「試験ポイント」を自分の言葉で説明する。
  4. 過去問道場の該当分野を解く。
  5. 85%未満なら、このマニュアルへ戻る。
