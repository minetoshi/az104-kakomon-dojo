↑上へLab 0　Cloud Shell / Subscription Context

安全目的: どのTenant / Subscriptionに対して実行しているかを確認します。

Get-AzContext Get-AzSubscription | Select-Object Name, Id, State Set-AzContext -SubscriptionId "<subscription-id>" Get-AzContext | Select-Object Account, Subscription, Tenant
基本: Get = 取得、New = 作成、Set = 変更、Remove = 削除。Verb-AzNounの形で読むと、未知のCmdletでも意味を推測できます。

よくある失敗

  • 別SubscriptionのContextのまま変更する
  • TenantとSubscriptionを混同する
  • 出力を確認せずコピー実行する

ミニ問題

Q1. 現在のContext確認は？
Get-AzContext。
Q2. Subscription切替は？
Set-AzContext。
Q3. 取得系Verbは？
Get-。

↑上へLab 1　Resource Group / Tag

低リスク目的: RGの取得、作成、Tag、削除予告を扱います。

Get-AzResourceGroup | Select-Object ResourceGroupName, Location Get-AzResourceGroup -Name "rg-az104-free-lab" New-AzResourceGroup -Name "rg-az104-ps-lab" -Location "japaneast" -Tag @{Purpose="AZ104"; Tool="PowerShell"} -WhatIf Remove-AzResourceGroup -Name "rg-az104-ps-lab" -WhatIf Get-Help New-AzResourceGroup -Full Get-Command *AzResourceGroup*
WhatIf: 実行した場合の変更を表示し、処理を実行しません。対応可否はCmdletごとにHelpで確認します。

ミニ問題

Q1. RG作成Cmdletは？
New-AzResourceGroup。
Q2. 変更予告は？
-WhatIf。
Q3. 詳細Helpは？
Get-Help Cmdlet名 -Full。

↑上へLab 2　RBAC

読み取り中心目的: Principal / Role / Scopeの3要素を出力から読みます。

Get-AzRoleDefinition | Where-Object Name -in @("Reader","Contributor","Owner","Tag Contributor") | Select-Object Name, Id Get-AzRoleAssignment -ResourceGroupName "rg-az104-free-lab" | Select-Object DisplayName, RoleDefinitionName, Scope Get-AzRoleAssignment -ObjectId "<object-id>"
書き込み例: 下は本当に権限を付与します。試験用Principalがなければ実行不要です。
New-AzRoleAssignment -ObjectId "<object-id>" -RoleDefinitionName "Reader" -ResourceGroupName "rg-az104-free-lab" # 代表Scope /subscriptions/<subscription-id> /subscriptions/<subscription-id>/resourceGroups/rg-az104-free-lab
試験: RBACは「誰に」「何のRoleを」「どのScopeで」。最小権限ではRoleだけでなくScopeも広げすぎない。

ミニ問題

Q1. Role Assignment一覧は？
Get-AzRoleAssignment。
Q2. RBACの3要素は？
Principal、Role、Scope。
Q3. RGを閲覧だけなら？
ReaderをRG Scopeに割り当てる。

↑上へLab 3　Storage

既存無料資産目的: Storage accountのSKU、Kind、TLS、Network設定を確認します。

$rg = "rg-az104-free-lab" Get-AzStorageAccount -ResourceGroupName $rg | Select-Object StorageAccountName, Kind, SkuName, PrimaryLocation $st = Get-AzStorageAccount -ResourceGroupName $rg -Name "<storage-account-name>" $st | Format-List StorageAccountName, Kind, SkuName, MinimumTlsVersion, AllowBlobPublicAccess, EnableHttpsTrafficOnly Get-AzStorageAccountNetworkRuleSet -ResourceGroupName $rg -Name "<storage-account-name>" Get-Help New-AzStorageAccount -Examples
読むポイント: Standard_LRS、StorageV2、Minimum TLS、Public access、DefaultAction、VirtualNetworkRules。

ミニ問題

Q1. Storage account一覧は？
Get-AzStorageAccount。
Q2. Firewall / VNet ruleは？
Get-AzStorageAccountNetworkRuleSet。
Q3. GPv2のKindは？
StorageV2。

↑上へLab 4　Virtual Machine

既存無料VM目的: VMのSize、Power state、Disk、NICをPortal表示と対応付けます。

$rg = "rg-az104-free-lab" Get-AzVM -ResourceGroupName $rg | Select-Object Name, Location, @{N="Size";E={$_.HardwareProfile.VmSize}} Get-AzVM -ResourceGroupName $rg -Status $vm = Get-AzVM -ResourceGroupName $rg -Name "vm-az104-free" $vm.StorageProfile $vm.NetworkProfile
状態変更: 以下は実際にVMを停止/起動します。12か月無料ハンズオンで作った対象VMだけに使ってください。
Stop-AzVM -ResourceGroupName $rg -Name "vm-az104-free" Start-AzVM -ResourceGroupName $rg -Name "vm-az104-free" Get-AzVM -ResourceGroupName $rg -Name "vm-az104-free" -Status
試験: VMの停止状態とDeallocatedを区別。VM削除後もDisk/NIC/Public IPが残る場合があります。

ミニ問題

Q1. Power stateまで取得するには？
Get-AzVM -Status。
Q2. Sizeはどこ？
HardwareProfile.VmSize。
Q3. 削除後に見るものは？
Disk/NIC/Public IPなど関連リソース。

↑上へLab 5　VNet / NSG / Route

読み取り中心目的: VNet、Subnet、NSG、UDRをPowerShellオブジェクトとして読みます。

$rg = "rg-az104-free-lab" $vnet = Get-AzVirtualNetwork -ResourceGroupName $rg -Name "vnet-az104-a" $vnet.AddressSpace.AddressPrefixes $vnet.Subnets | Select-Object Name, AddressPrefix, NetworkSecurityGroup, RouteTable $nsg = Get-AzNetworkSecurityGroup -ResourceGroupName $rg -Name "nsg-az104-app" $nsg.SecurityRules | Sort-Object Priority | Select-Object Name, Priority, Direction, Access, Protocol, SourceAddressPrefix, DestinationPortRange Get-AzRouteTable -ResourceGroupName $rg | Select-Object Name, Location, Routes
$nic = Get-AzNetworkInterface -ResourceGroupName $rg -Name "<nic-name>" Get-AzEffectiveNetworkSecurityGroup -NetworkInterfaceName $nic.Name -ResourceGroupName $rg Get-AzEffectiveRouteTable -NetworkInterfaceName $nic.Name -ResourceGroupName $rg
試験: NSGはPriorityの小さい数字が先。NIC/Subnet両方にNSGがあれば両方で許可が必要。

ミニ問題

Q1. VNet取得は？
Get-AzVirtualNetwork。
Q2. NSGルールの確認順は？
Priority昇順。
Q3. NICへ実際に適用されるNSG結果は？
Get-AzEffectiveNetworkSecurityGroup。

↑上へLab 6　Bicep / ARM Deployment

WhatIf中心目的: 既存Bicepを変更してデプロイするPowerShell側を補完します。

$rg = "rg-az104-free-lab" New-AzResourceGroupDeployment -ResourceGroupName $rg -TemplateFile "./main.bicep" -WhatIf New-AzResourceGroupDeployment -ResourceGroupName $rg -TemplateFile "./main.bicep" -TemplateParameterFile "./main.bicepparam" -WhatIf # 実デプロイは内容確認後のみ # New-AzResourceGroupDeployment -ResourceGroupName $rg -TemplateFile "./main.bicep"
Microsoft Learn: New-AzResourceGroupDeploymentのWhatIfは、Cmdletを実行した場合の変更を示し、デプロイ自体は実行しません。
対応: PowerShell = New-AzResourceGroupDeployment。CLI = az deployment group create / what-if。

ミニ問題

Q1. RGスコープのデプロイCmdletは？
New-AzResourceGroupDeployment。
Q2. 差分確認だけなら？
-WhatIf。
Q3. CLIの対応系統は？
az deployment group。

↑上へLab 7　Monitor / Activity Log

読み取り目的: 「Azure側で何が起きたか」と「リソースのメトリック」を追います。

Get-AzActivityLog -StartTime (Get-Date).AddHours(-6) | Select-Object EventTimestamp, OperationName, Status, ResourceGroupName, Caller | Sort-Object EventTimestamp -Descending Get-AzMetricDefinition -ResourceId "<resource-id>" | Select-Object Name, Unit, PrimaryAggregationType Get-AzMetric -ResourceId "<resource-id>" -MetricName "Percentage CPU" -StartTime (Get-Date).AddHours(-1)
試験: Activity LogはAzure Resource Manager側の管理プレーンイベント。VM内アプリログやLog Analyticsログとは別。

ミニ問題

Q1. 管理プレーンのSubscriptionイベントは？
Get-AzActivityLog。
Q2. 利用可能なMetric名は？
Get-AzMetricDefinition。
Q3. Activity LogはVMアプリログと同じ？
違います。

↑上へLab 9　総合障害シナリオ

シナリオ: rg-az104-free-lab内のVMが通信できない。変更はまだしたくない。VM状態、NIC、NSG、Route、直近の管理操作をPowerShellで確認する。
Step 1. VM状態
Get-AzVM -ResourceGroupName $rg -Name $vmName -Status
Step 2. NIC参照
(Get-AzVM -ResourceGroupName $rg -Name $vmName).NetworkProfile.NetworkInterfaces.Id
Step 3. NIC取得
Get-AzNetworkInterface -ResourceGroupName $rg -Name $nicName
Step 4. Effective NSG
Get-AzEffectiveNetworkSecurityGroup -NetworkInterfaceName $nicName -ResourceGroupName $rg
Step 5. Effective Route
Get-AzEffectiveRouteTable -NetworkInterfaceName $nicName -ResourceGroupName $rg
Step 6. 直近Activity Log
Get-AzActivityLog -StartTime (Get-Date).AddHours(-6)
狙い: いきなり変更せず、Get系で現在状態を集めて原因候補を潰してから変更する。実務にもAZ-104のトラブルシューティングにも効きます。
